# Changelog

## 2026-10-25
- Added "Razer QA Companion-AI" to QA & Playtesting (90 cards). It is a vision-based QA tool built on Amazon Bedrock that finds physics, collision, rendering and animation bugs in gameplay footage, writes bug reports with repro steps and video, and generates test cases from prompts or design documents. The GDC 2026 version (9 Mar 2026) needs no SDK, plugin or code changes. It has been on AWS Marketplace since 13 Nov 2025. Gameplay agents to run the tests are still in development, and no pricing is published. The "zero-integration" claim is Razer's. No efficiency figure is published. (The "up to 40%" figure in Razer's AWS post is general industry research, not a figure for this tool, so I left it out.)
  - Primary: https://www.razer.com/newsroom/company-news/razer-at-gdc-2026, https://www.razer.com/newsroom/company-news/razer-qa-companion-available-on-aws-marketplace
  - Independent (GDC 2026 version, zero-integration, vision-based detection, test generation, agents in development): https://www.pocketgamer.biz/razer-reveals-ai-tools-to-speed-up-game-development-pipelines/
- Updated "SideFX Houdini (ML toolset)" to "SideFX Houdini 22 (ML toolset)" (VFX). Houdini 22 (July 2026) adds TOP nodes to train computer-vision models (object detection, masking, keypoint tracking) and 3D Gaussian Splats from posed images, plus production-ready Gaussian Splat tools. Added the ML docs link. The efficiency entry is unchanged.
  - Primary: https://www.sidefx.com/docs/houdini/news/22/pdg.html, https://www.sidefx.com/docs/houdini/ml/index.html
  - Independent (release, production-ready Gaussian Splats): https://cgpress.org/archives/houdini-22-is-out.html
