# Game Pipeline AI Toolkit

Catalogue of AI tools for each game production discipline (2D, 3D, texturing, rigging, animation, VFX, engine integration, rendering, audio, QA, localization, trailers and UA). Each tool lists what it does, strengths, weaknesses and an evidence-graded efficiency gain. Status as of October 2026.

Live site: https://fyliu367.github.io/game-ai-toolkit/
